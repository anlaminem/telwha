Loan approval & credit risk в R

Логістична модель схвалення кредиту на синтетичному датасеті: які фактори важать найбільше, як виглядає поріг класифікації та що з цього важливо продукту й кредитній політиці.

5000 заявок · 10 змінних Credit score · Income · Employment R · tidyverse · glm · pROC

Що я моделюю

Ціль — змоделювати рішення банку Approved / Rejected для кредитної заявки на основі базових змінних ризику: скор, дохід, сума кредиту, досвід роботи, тип зайнятості та кілька демографічних полів.

Датасет: 5000 заявок, 10 змінних (Age, Income, LoanAmount, CreditScore, YearsExperience, Gender, Education, City, EmploymentType, LoanApproved). Таргет — loan_status_binary на основі LoanApproved.

Результат моделі

Логістична регресія дає AUC ≈ 0.90 на тесті, тобто добре розрізняє заявки, які система схвалює, і ті, які відхиляє.

Найсильніші предиктори: CreditScore, Income та EmploymentType (Unemployed як різко негативний фактор). Вік, освіта, місто і гендер у цій конфігурації не дають істотного внеску в рішення.

Поріг класифікації

Я порівнюю пороги 0.5 і 0.4 для P(Approved). Поріг 0.5 дає менше false positives, але більше відмов хорошим клієнтам. Поріг 0.4 збільшує кількість Approved, зменшує кількість помилкових відмов і паралельно піднімає ризик портфеля.

Візуалізації

Код (фрагмент) 


library(tidyverse)
library(pROC)

# дані --------------------------------------------------------

loan_data <- read_csv("loan_approval_data.csv")

loan_data <- loan_data %>%
  mutate(
    loan_status_binary = factor(
      if_else(LoanApproved == 1, "Approved", "Rejected"),
      levels = c("Rejected", "Approved")
    ),
    Gender         = factor(Gender),
    Education      = factor(Education),
    City           = factor(City),
    EmploymentType = factor(EmploymentType)
  )

loan_data_model <- loan_data %>%
  select(
    loan_status_binary,
    Age, Income, LoanAmount, CreditScore, YearsExperience,
    Gender, Education, City, EmploymentType
  )

set.seed(123)

train_idx  <- sample(
  seq_len(nrow(loan_data_model)),
  size = 0.8 * nrow(loan_data_model)
)

train_data <- loan_data_model[train_idx, ]
test_data  <- loan_data_model[-train_idx, ]

# модель ------------------------------------------------------

loan_model <- glm(
  loan_status_binary ~ .,
  data   = train_data,
  family = binomial(link = "logit")
)

test_probs <- predict(
  loan_model,
  newdata = test_data,
  type    = "response"
)

roc_obj <- roc(
  response  = test_data$loan_status_binary,
  predictor = test_probs,
  levels    = c("Rejected", "Approved"),
  direction = ">"
)

auc(roc_obj)
